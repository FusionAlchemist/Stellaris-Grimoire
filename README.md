# Stellaris Grimoire

An open-ended relational reference system for AI-assisted reasoning, construction and exploration.

## What is this?

The Stellaris Grimoire is a collection of computational concepts, fictional motifs, relationships and composition operators. It is provided as three reference files:

- **SPELLS.txt** — computational concepts mapped to motifs, system functions, implementation analogues and use cases.
- **CLOTHS.txt** — combinations and layered patterns with potential system functions and implementation analogues.
- **OPERATORS.txt** — the operator grammar and an appended research-operator extension, including provenance and qualifications.

The Grimoire is **not an autonomous agent**. A human or AI practitioner selects an objective, interprets the references and decides how, or whether, to apply them. Examples are illustrative, not claims that every listed combination has been independently implemented or verified.

## Getting started

**New to the Grimoire?** Read [How to Use the Stellaris Grimoire](HOW_TO_USE.md) for example prompts, three exploration approaches, operator guidance, and a worked illustration.

## An open invitation

Choose your own objective, domain and method. Read the files, follow any connections that interest you, and create, investigate or interpret something. You do not need to use every entry or follow a prescribed pipeline.

If you share your experience, we'd be interested in what you attempted, which references you used, what you actually produced or observed, what did not work, and any unexpected connections. Distinguish evidence from interpretation; preserve attribution and provenance when proposing new operators.

## Notes on the operator edition

`OPERATORS.txt` preserves the original 42-operator grammar and adds research entries recovered from prior mathematical investigations. Some appended entries are explicitly marked partial: they are historical records, **not** reconstructed full specifications. The original grammar's restriction on symbolic names concerns software products *created using* the method, not this reference repository itself.
